# Проект сервиса управления рассылками, администрирования и получения статистики

## Данный проект создан с использованием фреймворка Django.
* Созданы шаблоны с использованием стилей bootstrap
* Создано приложение 'mailing'
* Добавлены модели "Получатель рассылки", "Сообщение", "Рассылка", "Попытка рассылки"
* Реализованы контроллеры регистрации, аутентификации пользователя в сервисе, входа, выхода из системы, просмотра и 
* редактирования профиля.
* Создано приложение 'users'
* Реализована модель пользователя
* добавлены формы авторизации и регистрации
* Созданы шаблоны для контроллеров CRUD-операций для приложений "mailing" и "users"
* в приложении ограничен доступ для неавторизованных пользователей
* в приложении реализована отправка на email приветственного письма 
* в приложении реализовано подтверждение почты пользователя
* Создана команда для создания группы "Менеджеры"
* Произведены настройки приложений согласно ТЗ
* Настроено серверное и пользовательское кэширование с помощью Redis
* Собрана страница с отчетами по рассылке для каждого пользователя
* Реализована отправка рассылки как через интерфейс, так и через командную строку
## Установка

* Клонируйте репозиторий

```bash
  https://github.com/SidorovDmitry/Python_Project_5
  ```

* Установите зависимости

```bash
   poetry install
```

## Запуск

```bash
  python manage.py runserver
```
